Souce files are stored in the ```example_files``` directory and will serve to run tests

At the moment just run the ```basic_test``` tests by executing the ```bash``` script in each directory. 
It will just show you if this install runs or not (no unit tests yet).
* test_LISA_with_default_basis/ : run LISA with default basis (for H2 molecule)
* test_LISA_with_set2-11-avqz/ : run LISA with set2-11-avqz (for H2 molecule), requires generation of set2-11-avqz in
  PACKAGE_HOME/basis/ directory
