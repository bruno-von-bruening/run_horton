Use this folder to define custom basis sets according to the basis set definition (currently under
src/qcp_run_horton/my_basis_set).

```
conda activate run_horton
generate_basis.py CAMCASP
```
This will generate the set2-11-avqz (set2 for all under Z=11, s-part of avqz for all elements Z>=11) which is currently
used as radial ISA basis.
